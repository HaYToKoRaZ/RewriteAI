Gizlilik Politikası (Privacy Policy)

Son Güncelleme / Last Updated: 01.10.2026 · Versiyon 1.3.0

🔒 Özet Taahhüt: RewriteAI, gizliliğinize %100 saygı duyar. Eklentimiz hiçbir kişisel verinizi, gezinme geçmişinizi veya API anahtarınızı kendi sunucularına TOPLAMAZ, KAYDETMEZ ve ÜÇÜNCÜ TARAFLARLA PAYLAŞMAZ.

1. Veri Toplama ve Depolama (Data Collection & Storage)

RewriteAI tamamen istemci taraflı (client-side) çalışan bir tarayıcı uzantısıdır. Eklentiyi kullanabilmek için girdiğiniz yapay zeka API anahtarları (Google Gemini, OpenAI, Claude, Groq vb.) yalnızca tarayıcınızın kendi güvenli yerel depolama alanında (chrome.storage.local) şifreli olarak barındırılır.

2. Metin İşleme ve Yapay Zeka Sağlayıcıları

Web sayfalarında seçtiğiniz ve dönüştürmek istediğiniz metinler yalnızca dönüşüm anında sizin tercih ettiğiniz resmi AI sağlayıcısının API uç noktasına (örneğin generativelanguage.googleapis.com veya api.openai.com) doğrudan gönderilir:

  • Herhangi bir aracı veya proxy sunucu kullanılmaz.
  • Metinleriniz hiçbir ara veritabanına kaydedilmez.
  • İşlenen metin doğrudan tarayıcınıza döner ve sayfaya uygulanır.

3. İzinler ve Amacı (Permissions Used)

  • storage: Tercihlerinizi ve API anahtarlarınızı tarayıcınızda yerel olarak saklamak için.
  • contextMenus: Web sayfalarında metin seçtiğinizde sağ tık menüsünde RewriteAI seçeneklerini sunmak için.
  • clipboardRead / clipboardWrite: Dönüştürülen metni panoya tek tıkla kopyalayabilmeniz veya yapıştırabilmeniz için.
  • activeTab / scripting: Seçili metni otomatik algılayıp sayfa içinde hızlı dönüştürme kutusu (Content Modal) açabilmek için.

4. Üçüncü Taraf Hizmetleri (Third-Party Services)

Eklenti, kullanıcının seçtiği yapay zeka modelleriyle doğrudan iletişim kurar. Bu sağlayıcıların kendi gizlilik sözleşmeleri geçerlidir:
