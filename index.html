🔒 Privacy Policy

Last Updated: October 01, 2026 · Version 1.3.0

RewriteAI never sends or stores your personal text data or API keys on external servers. All user credentials remain encrypted in your browser's chrome.storage.local.

1. Direct Client-to-API Architecture

Transformations are routed directly and securely between your browser and the selected AI endpoint (Google, OpenAI, Groq, etc.). Zero telemetry, zero middlemen.

2. Permissions Used

  • storage: Save settings & API keys locally.
  • contextMenus: Launch rewrite options from right-click context menu.
  • clipboardRead / Write: Copy polished text to clipboard.
  • activeTab / scripting: Trigger the quick in-page editor modal.
