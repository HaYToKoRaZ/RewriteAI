### 🚀 Kurulum & Geliştirici Modu (Manuel Yükleme)

1. Bu depoyu indirin veya klonlayın:
   ```bash
   git clone https://github.com/HaYToKoRaZ/RewriteAI.git
   ```
2. Tarayıcınızda uzantılar sayfasını açın:
   - **Chrome:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
3. Sağ üstteki **"Geliştirici Modu" (Developer Mode)** anahtarını açın.
4. **"Paketlenmemiş Öğe Yükle" (Load unpacked)** butonuna tıklayın.
5. Proje içindeki **`main`** klasörünü seçin.
6. Eklenti simgesine sağ tıklayıp **Seçenekler (Options)** sayfasına gidin ve ücretsiz Gemini / OpenAI / Groq API anahtarınızı girin.

## 🇬🇧 English Description

### 📌 What is RewriteAI?
**RewriteAI** is a cutting-edge browser extension designed to instantly rewrite, summarize, polish, or transform any selected text on the web into 12 distinct tones using world-class AI models.

Engineered with Manifest V3 and pure ES Modules, all API communication runs strictly peer-to-peer between your browser and official AI provider endpoints. Your API keys are encrypted in `chrome.storage.local` and never touch any middleman server.

### ✨ Key Features

1. **Context-Aware Workflow:**
   - **In-Page Floating Modal:** Right-click any selected text to trigger an instant floating editor right where you read.
   - **Action Popup:** Accessible from your browser toolbar with real-time model switching and live tone preview.
2. **12 Tailored Writing Tones:**
   - 💼 *Professional* &nbsp;|&nbsp; 👔 *Formal* &nbsp;|&nbsp; ☕ *Casual* &nbsp;|&nbsp; ⚡ *Summarize* &nbsp;|&nbsp; 📖 *Elaborate*
   - 🎨 *Creative* &nbsp;|&nbsp; 🎓 *Academic* &nbsp;|&nbsp; 💻 *Technical* &nbsp;|&nbsp; 📣 *Marketing* &nbsp;|&nbsp; 🔤 *Fix Grammar*
3. **Multi-Model Support:**
   - Gemini (2.5 Flash, Pro), OpenAI (GPT-4o, Mini), Anthropic Claude, Groq (ultra-low latency Llama 3.3), DeepSeek, Cohere, Hugging Face.
4. **Zero Data Telemetry:**
   - Pure client-side execution. Zero server logging. Full privacy guaranteed.
5. **Bilingual UI:** Native support for English and Turkish across settings, popup, and in-page modals.

### 🛠️ Developer Setup & Unpacked Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/HaYToKoRaZ/RewriteAI.git
   ```
2. Navigate to your browser extensions manager:
   - **Chrome / Helium:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the **`main`** folder.
5. Right-click the extension icon, choose **Options**, enter your preferred API key, and begin rewriting!
