## 🇬🇧 English Description

### 📌 What is RewriteAI?
**RewriteAI** is an advanced, privacy-first browser extension engineered to rewrite, summarize, polish, or transform any highlighted text on any website into 12 distinct tones using top-tier AI models.

Built entirely on Manifest V3 and pure ES Modules without cumbersome bundlers, all API communications are made directly from your browser to the official AI endpoints. Your sensitive API credentials and text inputs are stored strictly inside your local browser storage (`chrome.storage.local`) and **never touch any intermediary server**.

### 📦 Installation Guide
You can download ready-to-use packages directly from [GitHub Releases](https://github.com/HaYToKoRaZ/RewriteAI/releases):
- Download the latest ZIP file (`RewriteAI-v*.zip`).
- Unzip the archive into any folder.
- Open your browser's extensions page (`chrome://extensions/` or `edge://extensions/`), enable **Developer Mode**, and click **Load unpacked**.
- Set up your API keys in Options and enjoy instant AI rewriting.
